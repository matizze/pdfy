# Limites editoriais

Os limites absolutos protegem legibilidade e recursos. Os limites visuais por bloco causam paginação automática, nunca truncamento ou redução ilegível.

| Campo | Limite |
|---|---:|
| Título do documento/seção | 90 caracteres |
| Subtítulo | 180 caracteres |
| Destinatário | 120 caracteres |
| Seções | 20 |
| Componentes por seção | 30 |
| Texto | 20.000 caracteres |
| Título interno | 70 caracteres |
| Descrição de card | 600 caracteres |
| Conteúdo de callout | 1.200 caracteres |
| Célula de tabela | 240 caracteres |

| Componente | Máximo absoluto | Bloco visual típico |
|---|---:|---:|
| metrics | 12 itens | 4 |
| highlights | 12 itens | 3 |
| cards | 24 itens | 6 |
| comparison | 30 linhas | conforme espaço |
| chart | 16 barras | 8 |
| steps | 18 itens | 6 |
| timeline | 21 itens | 7 |
| table | 200 linhas, 2-6 colunas | conforme espaço |
| investment | 30 itens | 8 |
| list | 60 itens | conforme espaço |
| signature | 4 signatários | 2 por linha |

Quando um bloco extenso não couber, continuar em outra página com cabeçalho repetido. Se um único item atômico não couber numa página interna vazia, reduzir o conteúdo ou dividi-lo semanticamente no JSON.
